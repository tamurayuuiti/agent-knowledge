# 11. 数値知見(全実測値の集約)

> **役割**: このプロジェクトの全実測値の集約。「記事のネタ・設計判断の根拠引き」のための素材全集。テーマ別の節(§A, §B, …)で構成し、新実験の結果は**追記**する(上書きしない)。
> **書式規定**: 表形式を基本とし、**全数値に出典を添える**(01 §5): 環境ラベル [S]/[L]/[R](このプロジェクトでの定義を下記に書く)+ run 名 + ファイルパス + 日付。環境・プラットフォームの生の実測データ(コマンド出力・スペック・検証結果)もここに置く(汎用 04 には正典化された結論のみ = 01 §5)。
> **更新規則**: 新しい実験結果・実測が出たらその都度追記。数値の「公式評価・判定」は追跡文書側(役割分担 = 01 §1 の二重管理)。
> **正典関係**: 数値の解釈・判定 = 追跡文書。来歴(シード・ハッシュ・バージョン)= 08 §2。run の所在 = 15。

**環境ラベルの定義**(このプロジェクト): [S] = サンドボックス実測 / [L] = ユーザーローカル実測 / [R] = 保存ファイル由来 / <追加があれば定義>
