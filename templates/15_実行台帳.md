# 15. 実行台帳(run/成果物の所在と状態)

> **役割**: 「あの run(成果物)はどこ? 何? 今の正典はどれ?」への**唯一の回答**。実験成果物の所在・状態・移行の履歴台帳。
> **書式規定**: ①アーカイブ所在地の表(場所 | 中身)②run 台帳の表(run 名 | 生成日時 | コード版 | 目的/役割 | 主要指標 | 状態)③データ配置の移行記録(旧→新の対応表 | 日付 | 決定番号)。**状態列**は「採用・公開中 / 不採用 / superseded by <run> / 実験記録」のいずれか(08 §5)。
> **更新規則**: run を実行・採用・移動した都度更新する。成果物は**削除せず放置 + 台帳記録**が原則(削除はユーザー判断 = 08 §5-5)。採用の真実源(Git 追跡の設定ファイル)を変更したら、その移行自体をここへ記録する(08 §5-2)。
> **正典関係**: run の数値の実測詳細 = 11。採用切替の操作 = 08 §5-2(真実源ファイルの編集+commit)。台帳原則の一般論 = 08 §5。
