# 16. 記事素材(アイデア帳)— 任意スロット

> **役割**: 将来の記事・発信の**アイデアバックログ**。knowledge 全体(ログ・知見・決定・失敗・環境調査)から、記事の種になる切り口・素材・数値・図版アイデアをここへ集約する。
> **位置づけの注意**: **執筆のコミットメントでも最新状態の説明でもない**(最新状態の正典は追跡文書)。素材が溜まったら追記して育てる。
> **書式規定**: ①切り口候補(アルファベット連番。各案 = フック / 核 / 山場・クライマックス / 読者 / **出典**)②パンチライン数値集(引用用。**数値出典の規律** = 01 §5)③図版ガイド(既存アセットの表 + 新規に作る価値がある図)④構成メモ(推奨アウトライン)。
> **更新規則**: 良い切り口・数値・図版 idea を発見するたびに追記する(チェックポイント単位)。出典のない数値をパンチラインにしない。
> **正典関係**: 数値の実体 = 11。失敗談の素材庫 = 13(と汎用 07)。記事化の実作業が始まったら work/<topic>.md を開設する(01 §4)。
