# 汎用knowledge — 原本(GitHub リポジトリ)

> **版**: v1.2(2026-11-24)/ **出所**: wikiuniverse プロジェクト knowledge/(2026-10-03 時点アーカイブ)から抽出・汎用化
> **性格**: 複数プロジェクトが**ライブ参照**する汎用knowledgeの原本(専用 GitHub リポジトリ・**public = 01 §12.6**。管理規則 = 01 §12)。プロジェクトはこのファイルをフォークせず、**clone + pull で参照**し、逸脱は override(プロジェクト 00 §7 = 01 §11)、改善は PR(01 §12.3)で行う。
> **プロジェクト固有knowledge**: 各プロジェクトのワークスペース `knowledge/<project>/`(00・10–16・20–・work/・プロジェクト README)に分離(配置規約 = 01 §1: `knowledge/generic/` = 本リポジトリの clone と由来で分離)。その移行・バックアップ = Google Drive(01 §12.5)。

## これは何か

**AI エージェント + 人間が複数プロジェクトにわたって継続開発するための知識・運用基盤**: 運用ルール(01)、開発規約(02)、Git 運用(03)、サンドボックス環境の性質(04)、秘密情報の扱い(05)、自律作業の手順(06)、汎用教訓集(07)、検証・計測規律(08)。**同梱ツール**: `tools/scan_lang.py`(混入監査)。

## 読み方(AI エージェント向け)

1. **セッション開始時**: 下記「起動チェックリスト」から始め、ポインタ先の必要な節だけ読む
2. **タスク別**: 「タスクマップ」→ ファイル§。各ファイル冒頭の**スコープ/非スコープ**を確認し、無いものを追わない
3. **異常時**: 「症状マップ」→ ファイル§
4. **一括読み込みをしない**: 1ファイル(10–25KB)が読み取り単位。航行(どこに何があるか)はこのファイルが担当する
5. **プロジェクト固有の情報はここに無い**: 状態・override・固定値はプロジェクト側 knowledge/(README・00)を読む

## 起動チェックリスト(毎セッション/ターンの開始時。詳細 = 06 §5)

1. **汎用knowledge clone の確認**: 無ければ clone(01 §10)/ あれば `git pull`(**セッション開始時または明示タスクのみ** = 01 §11 pull 規律)
2. **HEAD の突合**: プロジェクト README「汎用knowledge 参照」の記録と一致するか。進んだ場合は CHANGELOG の **[重大]** を確認(01 §11/§12.3)
3. 現在地の確認: プロジェクト・ブランチ・HEAD・`git status`(→ 06 §5)
4. `.git` の有無確認(プロジェクト・知識リポ双方)→ 無ければ方式Aで復旧(→ 03 §7。消失の事実 = 04 §1/§3)
5. 認証が必要な作業なら: 認証機構の再構築(→ 05 §8。HOME 側は揮発 = 04 §1)
6. 整合性: 汎用 clone = `git status` clean(01 §11)/ プロジェクト knowledge/ = マーカー電池(設定済みなら。04 §7)→ MISMATCH 時は実装・編集を中止し報告
7. work/・PR・関連資料の状態確認(→ 06 §5)
8. **実状態優先**: origin/コード/テストの実測 > 要約・過去報告・knowledge の記述(→ 06 §6)

## 症状 → ファイル§ マップ

| 症状 | 読む先 |
|---|---|
| `fatal: not a git repository` / .git が無い | 03 §7、04 §3(教訓 = 07 U5) |
| 文字化け / UnicodeEncodeError / テストが cp932 で落ちる | 07 U1、02 §5 |
| 文書ファイルが複製・キメラ化している | 07 U2 |
| 文書内に `"$ARENA_WORKSPACE"` 等の文字列が混入 | 07 U3、04 §2 |
| ZIP・ファイルがワークスペース外(/tmp)に展開された | 07 U4、04 §2 |
| 前ターンの変更が消えた/改訂が混在している(torn state) | 04 §3/§7、07 U5、復旧 = 03 §1 |
| **汎用 clone に予期しないローカル差分がある** | **01 §11(git 検出・復旧)** |
| 並列ジョブの「完了済み」が信用できない/再計算された | 07 U7、08 §1 |
| 生成物を読み込んだら KeyError(列・キーが無い) | 07 U8 |
| import が壊れた/新パッケージが既存を隠した | 07 U9 |
| 集計値が明らかに桁違い(申告 vs 実測) | 07 U10、08 §6 |
| 実行が「速すぎる」/出力値があり得ない | 07 U11 |
| 指標が「改善」したのに分割/結果が壊れて見える | 07 U12、08 §3 |
| 表示・出力にフォールバック値(無音の代替)が現れる | 07 U6 |
| numpy の代入が一部しか効いていない | 07 U13 |
| **検査・監査が「検出 0 件 / 合格」なのに問題が見つかった** | **07 U14、08 §6-6** |
| 文書に他言語の字形(簡体字等)が混ざっている | 01 §3・§14.1、02 §4、`tools/scan_lang.py` |
